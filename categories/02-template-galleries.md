# 02 · Template Galleries

这一组用来判断“完整场景长什么样”，比单个 transition 更接近真实内容。

## S — 先看

### Locomotion
- Repo: [locomotion-pro/locomotion](https://github.com/locomotion-pro/locomotion)
- Preview / Studio: https://locomotion.pro
- 当前 README：67 templates、6 style variants（Default / Brutalist / Rounded / Minimal / Glass / Neo）。
- 看点：**同一动画骨架换不同视觉主题**，非常适合参考我们未来的 `Style × Palette × Rhythm` 结构。
- License：仓库暂未发现明确 LICENSE，当前仅作视觉 / 结构参考。

### RVE Remotion Templates
- Repo: [reactvideoeditor/remotion-templates](https://github.com/reactvideoeditor/remotion-templates)
- Live Demos: https://www.reactvideoeditor.com/remotion-templates
- 当前 README：81 个 self-contained components。
- 类别包括 Charts & Data / Text / Content Animation / Background / Cinematic / Transition / Logo & Branding 等。
- License：GitHub repo metadata 当前没有声明许可证，因此现在只看，不复制。
