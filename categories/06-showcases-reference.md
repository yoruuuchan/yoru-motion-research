## 规则

Discovery repository 只负责产生新候选。任何候选进入主目录前仍要过：

1. 确认不是 fork / 垃圾 demo / 一次性 assignment；
2. 有可看的 preview 或明确独特的实现价值；
3. 查清 license；
4. 再放进 `data/repos.yml` 的 S/A/B 主筛选队列。
