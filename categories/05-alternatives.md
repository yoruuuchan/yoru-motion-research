# 05 · Adjacent Frameworks / Alternatives

这组目前的目的不是“换掉 Remotion”，而是偷师不同框架擅长的 motion language 和产品架构。

## Motion Canvas
- [motion-canvas/motion-canvas](https://github.com/motion-canvas/motion-canvas)
- TypeScript / Canvas / generator-style timeline。
- **最值得看**：矢量动画、技术解释、旁白同步、diagram/explainer movement。
- License：MIT（已核验）。

## Revideo
- [midrender/revideo](https://github.com/midrender/revideo)
- TypeScript 视频模板 / dynamic input / programmatic generation 路线。
- **最值得看**：自动化输入、模板 API、视频产品化。
- License：MIT（已核验）。

## Manim
- [ManimCommunity/manim](https://github.com/ManimCommunity/manim)
- Python 数学、几何、技术解释动画。
- **最值得看**：知识转译、diagram choreography、抽象概念逐步呈现。
- 不是人物采访 / Vlog / Editorial 的主要来源。

## MoviePy
- [Zulko/moviepy](https://github.com/Zulko/moviepy)
- Python editing / compositing / batch processing。
- **最值得看**：批处理与后处理能力，不是视觉模板审美。

## 使用规则

相邻框架如果出现我们特别喜欢的效果，先抽象成“动作原则”，然后再判断是否值得在 Remotion 中重写；不要为了一个效果把整个工作流切成多框架拼盘。
