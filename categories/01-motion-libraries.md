# 01 · Motion Libraries / Components

这一组是第一轮最重要的：找“动作词汇”和可复用组件。

## S — 先看

### video-shotcraft
- Repo: [Vincentwei1021/video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft)
- Gallery: https://vincentwei1021.github.io/video-shotcraft/
- 当前 README：152 shot recipe cards / 209 motion previews。
- 看点：镜头运动、产品展示、转场、2.5D、节奏、声音设计。
- 初步判断：**最适合拿来建立 YORU 的 motion vocabulary。**

### Remotion Bits
- Repo: [av/remotion-bits](https://github.com/av/remotion-bits)
- Gallery: https://remotion-bits.dev
- 看点：文字、渐变转场、粒子、3D、低层 motion utilities。
- 特别价值：CLI + MCP + Skill + registry，非常像未来我们自己的组件分发形态。

### Clippkit
- Repo: [reactvideoeditor/clippkit](https://github.com/reactvideoeditor/clippkit)
- Preview: https://clippkit.com
- 看点：Intro、Text Effect、Transition、Scene、timing/layout utilities。
- 特别价值：把 Remotion 组件做成“像 UI library 一样”的组织思路。
- License：正式复用前继续核验。
