# 03 · Editors / Timelines

这一类解决的不是“画面好不好看”，而是未来我们怎么让模板被人快速选择、组合和修改。

## React Video Editor — Open Source Edition
- Repo: [reactvideoeditor/free-react-video-editor](https://github.com/reactvideoeditor/free-react-video-editor)
- Demo: https://www.reactvideoeditor.com/open-source
- 能力：浏览器时间线、视频 clip 排列、文字 overlay、实时 Remotion Player preview。
- 价值：研究未来 `Motion Research Gallery → Template Picker → Timeline → Render` 的 UI 结构。
- **许可证提醒**：README 明确写的是 RVE 自定义许可，并提醒 Remotion 许可另算。当前只作架构参考，不复制代码。

## Locomotion Studio
- Repo: [locomotion-pro/locomotion](https://github.com/locomotion-pro/locomotion)
- Studio: https://locomotion.pro/studio
- 能力：template browser、drag & drop、timeline、live preview、AI chat、code export。
- 价值：观察“模板研究库怎样变成可操作的视频生产界面”。
