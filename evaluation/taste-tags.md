# Motion Taste Tags — v0.1

> 这不是最终分类标准，只是为了让 Yoru 筛选时不用每次重新发明词。最终以实际留下来的作品反推 taxonomy。

## Style

| Tag | 典型观感 | 常见视觉语言 |
|---|---|---|
| `editorial` | 舒缓、杂志感、有呼吸 | 留白、细线、排版、慢推拉、图像裁切 |
| `fresh` | 轻快、小清新、明亮 | 柔色、圆角、小图标、照片拼贴、轻弹性 |
| `playful` | 活泼、趣味、年轻 | 高饱和、几何、贴纸、手绘、弹跳 |
| `kinetic` | 强卡点、冲击、快速 | 超大字、硬切、快速缩放、闪帧、切片 |
| `tech-ui` | 数字、精密、界面感 | 网格、窗口、HUD、代码、scan、data |
| `experimental` | 艺术、非常规、不可预测 | 错位、颗粒、glitch、蒙版、抽象图形 |
| `cinematic` | 情绪、沉浸、重量 | 黑场、环境音、电影字幕、match cut |
| `documentary` | 稳定、真实、信息清楚 | lower third、地点时间、轻推、声音桥 |
| `fashion-pop` | 酷、视觉优先、年轻 | 强 typography、撞色、裁切、闪光灯、封面感 |

## Purpose

`intro` · `outro` · `transition` · `title` · `lower-third` · `image-motion` · `caption` · `data` · `logo` · `background` · `ui-scene` · `3d-scene` · `sfx`

## Rhythm

- `slow` — 舒缓口播、纪录、访谈、情绪段落
- `medium` — 常规人物、艺术、产品解释、Vlog
- `fast` — 强卡点、预告、短视频开场、产品 launch

## Motion primitives

`fade` · `slide` · `push` · `wipe` · `mask` · `zoom` · `whip` · `spring` · `stagger` · `parallax` · `split` · `glitch` · `film-burn` · `blur` · `scale` · `rotate` · `typewriter` · `counter` · `path-draw` · `particle` · `camera`

## Palette direction — placeholder

颜色最终应该成为独立 preset，而不是写死在模板里。每套 palette 至少定义：

```text
background
surface
primary
secondary
accent
text
muted
line
```

目前准备观察的方向：

- `warm-paper`
- `aozora`
- `soft-mint`
- `pop-candy`
- `signal-red`
- `electric-blue`
- `film-neutral`
- `project-derived`（从具体艺术家 / 品牌素材中抽取限定色）

## Anti-tags / rejection vocabulary

这些词也值得记录，因为“我讨厌什么”会帮助 Agent 少抽风：

`ppt-like` · `generic-tech-blue` · `particle-overkill` · `cheap-glitch` · `template-commercial` · `over-rounded` · `too-flat` · `visual-noise` · `weak-hierarchy` · `color-clash` · `slow-for-no-reason` · `over-animated`
