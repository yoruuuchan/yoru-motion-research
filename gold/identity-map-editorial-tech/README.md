# Identity Map · Editorial Tech

**类型**：采访自我介绍 / 人物身份结构可视化  
**状态**：已批准 gold exemplar  
**画幅**：1920×1080 / 30fps  
**时长**：31.633s  
**能量**：低开 → 中段展开 → AI 节点成为重心 → 克制收束

## 什么时候直接用我

当采访对象在一段连续自我介绍里依次说到：**姓名 → 两个并列身份 → 跨学科身份 → 所属/创办组织 → 组织属性 → 当前主要工作 → 两个细分方向 → 近期重心 → 个人创作**，直接以本条为母版，只换真实内容与字幕对齐点，不重新设计。

这条不是普通字卡。它用一个连续的 2D 信息空间把人物身份关系“长出来”，适合缺少 B-roll、但自我介绍信息结构清晰的采访段落。

## 视觉语言

- **YORU Content**：借信息层级、编辑排版、克制留白。
- **KUNLUN**：借深色底、切角节点、青色信号线、结构关系与空间横移。
- **视频边缘保持干净**：禁止顶部/底部/左右装饰横线、角落状态小字、页码、预埋 Logo、设计系统署名或其他“页面家具”。最终品牌 Logo / 栏目包装由后期统一叠加。
- 保留的线条只能承担内容内部的关系叙事：身份合流、组织展开、教学分支、重心转移。
- 不使用虚构科技指标、假系统状态、装饰性 HUD。

## 参数与实现

- 参考画布：1920×1080；源码内部 960×540 渲染后 Lanczos 放大到 1080p。
- 30fps；批准版总长 949 帧（31.633s）。
- 动效由确定性函数驱动，无随机数。
- 主色：`#00B8FF`；背景：`#06080d`；面板：`#0d1320`；正文：`#F2F5F5`。
- 字体：中文默认系统 `Noto Serif CJK SC`；等宽英文优先 `JetBrains Mono`，不可用时允许通过 `MONO_FONT` 指向替代字体。字体文件不入库。
- `render_identity-map.js` 依赖 Node.js、`skia-canvas`、FFmpeg。

### 渲染

```bash
npm i skia-canvas
node render_identity-map.js output.mp4
```

### 导出关键帧

```bash
node render_identity-map.js --still 120 stills/04s.svg
```
